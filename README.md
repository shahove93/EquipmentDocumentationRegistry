# Equipment Documentation Registry

Система для хранения и структурирования паспортов, сертификатов и сопроводительной
документации на материалы и оборудование.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `app/` | исходный код приложения |
| `tests/` | тесты |
| `storage/` | локальное файловое хранилище документов (PDF/JPG/PNG) |
| `.env` | настройки окружения (не отслеживается в git) |
| `.venv/` | виртуальное окружение Python (не отслеживается в git) |

## Окружение разработки

- Ubuntu 26.04.1 LTS (WSL2)
- Python 3.14.4, виртуальное окружение `.venv` (pip 25.1.1)
- PostgreSQL 18.6, локальный кластер `18/main`, база `equipment_docs`, роль `edr`
