# Веб-интерфейс Equipment Documentation Registry

React + Vite + TypeScript поверх существующего FastAPI-приложения. Собранного
backend здесь нет: интерфейс обращается к API по относительным путям, а dev-сервер
Vite проксирует их на `127.0.0.1:8000`, поэтому CORS не нужен и не включён.

> **Только для локальной разработки.** Авторизации нет, данные и файлы доступны
> любому, кто открыл порт. Публиковать приложение в интернет нельзя.

## Запуск: два терминала

Оба сервера должны оставаться запущенными, пока вы работаете с интерфейсом:
если остановить backend, экраны покажут «Сервер недоступен».

**Терминал 1 — backend** (из корня репозитория):

```bash
./.venv/bin/python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

**Терминал 2 — frontend:**

```bash
cd frontend
npm run dev -- --host 127.0.0.1
```

Открыть: **http://127.0.0.1:5173** (тот же адрес через `localhost` тоже работает).

Первый запуск в новом клоне требует установки зависимостей:

```bash
cd frontend
npm install
```

`frontend/node_modules/` и `frontend/dist/` в репозиторий не попадают.

## Что доступно

| Адрес | Экран |
| --- | --- |
| `/` | реестр документов: фильтры, постраничный просмотр, статусы |
| `/documents/new` | создание карточки |
| `/documents/<id>` | карточка: реквизиты, типоразмеры, вложения, история проверок |

Основной сценарий: создать сертификат → прикрепить PDF/JPEG/PNG → выбрать
типоразмеры → подтвердить или отклонить документ → посмотреть историю.

## Проверки

```bash
cd frontend
npm run typecheck   # tsc --noEmit
npm run build       # production-сборка в dist/
```

## Замечания по окружению

- Backend и его база запускаются отдельно; интерфейс не хранит данные у себя и не
  кэширует документы — каждый экран читает состояние заново после записи.
- Vite проксирует только API. `/docs`, `/redoc` и `/openapi.json` остаются на
  `http://127.0.0.1:8000/docs`.
- Если браузер в Windows не открывает `localhost:5173` при включённом системном
  прокси, добавьте `localhost;127.0.0.1` в исключения прокси.
