Probe content (same structure as the workflow step)
---------------------------------------------------
$ErrorActionPreference = 'Stop'
cmd /c exit 7
if ($LASTEXITCODE -ne 0) { throw "first native command failed with exit code $LASTEXITCODE" }
cmd /c exit 0
if ($LASTEXITCODE -ne 0) { throw "second native command failed with exit code $LASTEXITCODE" }

The failing native command aborts via `throw` before the later succeeding
`cmd /c exit 0` can run, so the outer exit is 1. A later success cannot mask it.

Both `npm ci` and `npm run build` are immediately followed by an explicit
`$LASTEXITCODE` check that throws, so the step stops on the first nonzero npm
exit. The YAML structural check `check-yaml.py` also asserts `shell: pwsh` and
exactly two `$LASTEXITCODE -ne 0` guards, with the first before `npm run build`.
